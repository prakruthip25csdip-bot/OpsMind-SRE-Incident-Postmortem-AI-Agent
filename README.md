# OpsMind / MemoraDesk — Frontend UI

React 18 + Vite + Tailwind CSS + Framer Motion user interface for **OpsMind SRE & Incident Postmortem AI Agent**.

## Setup & Running Locally

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Configure Backend URL (defaults to http://localhost:8000):**
   ```bash
   # Optional: create .env
   VITE_API_BASE_URL=http://localhost:8000
   ```

3. **Start development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
